Scheme-less Address Bar BitB Popup

Modern browsers often hide https:// in the address bar and display only the domain path (sso.example.test/auth/login). This edge case evaluates how the heuristic engine behaves when the URL scheme is omitted.

Expected Detection & Analysis Value: Medium Risk (50/100) — because the URL regex looks for http(s)://, omitting the scheme drops the score from 100 to 50, yet the window is still flagged via floating container (+10) + Windows controls (+25) + password input (+15). Ideal for discussing heuristic limitations in the report.
